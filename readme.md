# Sistema de Desconto Progressivo - Agenda 06

Este projeto em Python foi desenvolvido para a disciplina de Desenvolvimento de Sistemas I.

## O que o programa faz:
Calcula descontos progressivos em compras de acordo com o valor total:
- Abaixo de R$ 200,00: 5% de desconto.
- Entre R$ 200,00 e R$ 299,99: 10% de desconto.
- A partir de R$ 300,00: 15% de desconto.

## Tecnologias utilizadas:
- Python
- VS Code
